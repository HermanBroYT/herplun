# HerPlun 1.1

Плагин для Minecraft-серверов **Spigot / Paper 1.12.2 и новее**:
баны, муты, жалобы, выдача привилегий и проверка на читы.

---

## Что нового в 1.1

- Работает на **1.12.2 и выше** (раньше — только 1.20.x).
- Новые команды: `/unban`, `/mute`, `/unmute`, `/voice`, `/herplun privilege`.
- Появилась папка настроек `plugins/HerPlun/` с файлом `config.yml`.
- Муты сохраняются в `mutes.yml` и **не пропадают после перезапуска**.

---

## Как обновиться с 1.0

Переустанавливать плагин с нуля **не нужно**:

1. Остановите сервер.
2. Удалите старый `HerPlun.jar` из папки `plugins` и положите новый.
3. Запустите сервер.

Баны хранятся самим сервером, поэтому остаются на месте. При первом запуске
создаётся папка `plugins/HerPlun/` с `config.yml`.

## Команды

| Команда | Что делает | Право |
|---|---|---|
| `/ban <игрок> [причина]` | Бан навсегда | `herplun.ban` |
| `/unban <игрок>` | Разбан игрока | `herplun.unban` |
| `/timeban <игрок> <время> [причина]` | Временный бан | `herplun.timeban` |
| `/mute <игрок> [время]` | Мут. Без времени — навсегда | `herplun.mute` |
| `/unmute <игрок>` | Снять мут | `herplun.unmute` |
| `/help` | Список команд | `herplun.help` |
| `/report <игрок> <причина>` | Жалоба на игрока | `herplun.report` |
| `/voice` | Кликабельная ссылка на голосовой чат | `herplun.voice` |
| `/check on <игрок> <время>` | Вызвать на проверку читов | `herplun.check.on` |
| `/check off [игрок]` | Завершить проверку | `herplun.check.off` |
| `/check tp` | Телепорт к проверяемому | `herplun.check.tp` |
| `/check time <время>` | Продлить проверку | `herplun.check.time` |
| `/herplun privilege set <игрок> <привилегия>` | Выдать привилегию навсегда | `herplun.privilege` |
| `/herplun privilege addtemp <игрок> <привилегия> <время>` | Выдать на время | `herplun.privilege` |
| `/herplun privilege remove <игрок> <привилегия>` | Снять привилегию | `herplun.privilege` |

**Формат времени:** `s` секунды, `m` минуты, `h` часы, `d` дни, `w` недели.
Можно объединять: `30m`, `12h`, `7d`, `1d2h30m`.

Если у игрока нет права, он увидит:
`"HerPlun" У вас нет прав что прописать команду!`

## Права (LuckPerms)

```
herplun.ban
herplun.unban
herplun.timeban
herplun.mute
herplun.unmute
herplun.help
herplun.report
herplun.voice
herplun.privilege
herplun.check.on
herplun.check.off
herplun.check.tp
herplun.check.time
```

Пример выдачи права модераторам:
`/lp group moderator permission set herplun.mute true`

---

## Привилегии (`/herplun privilege`)

Команда управляет **группами LuckPerms**, поэтому на сервере должен стоять
плагин **LuckPerms**. Группа (например `vip`) должна быть создана заранее:
`/lp creategroup vip`.

- `set` — игрок получает группу навсегда.
- `addtemp` — группа на время, потом снимается сама.
- `remove` — группа снимается.

---

## Голосовой чат (`/voice`)

Команда присылает игроку кликабельную ссылку. Плагин ничего не скачивает
на сервер. Ссылку можно заменить на любую в `config.yml` (`voice.link`).

---

## Настройка (`plugins/HerPlun/config.yml`)

Можно изменить префикс, сообщения о нехватке прав и о муте, ссылку
для `/voice` и список команд, запрещённых замученным (`/msg`, `/tell` и т.д.).
Изменения применяются после перезапуска сервера.

> ⚠️ **Внимание!** Ошибка в `config.yml` (лишний пробел, неверный отступ,
> пропущенная кавычка) может сломать плагин, а в худшем случае привести
> к **краху сервера**. Перед правкой сделайте копию файла. Меняйте только текст
> внутри кавычек. Если что-то сломалось — удалите `config.yml`, и при запуске
> он создастся заново.

## Как работает проверка на читы

1. Модератор пишет `/check on <игрок> <время>`.
2. Игрок замораживается: не двигается, не ломает и не ставит блоки, не пишет
   команды. Чат остаётся доступен.
3. Модератор может телепортироваться к нему (`/check tp`) или продлить время
   (`/check time`).
4. Если игрок вышел или время закончилось — **бан навсегда**.
5. Если проверка пройдена — `/check off`.

Список активных проверок хранится в памяти и сбрасывается при перезапуске.

---

## Возможные конфликты

Команды `/ban`, `/unban`, `/mute`, `/help` есть в других плагинах
(EssentialsX и т.п.). Если срабатывает не та команда, пишите
`/herplun:ban`, `/herplun:mute` и так далее.

## Сборка .jar через GitHub

1. Загрузите все файлы проекта в репозиторий GitHub.
2. Вкладка **Actions** → **Build HerPlun** → последний запуск.
3. Внизу в **Artifacts** скачайте `HerPlun`. Внутри лежит `HerPlun.jar`.
