# HerPlun 1.2

Плагин для Minecraft-серверов **Spigot / Paper 1.12.2 и новее**:
баны, муты, жалобы с меню, привилегии, технические работы, анти-чит,
проверка на читы и `/gm`.

---

## Что нового в 1.2

- **`/report open`** — меню жалоб. Игрок видит свои жалобы и может их отменить.
- **Файлы данных** в `plugins/HerPlun/`: `bans.yml`, `mutes.yml`, `reports.yml`.
- **`/herplun technical on/off`** — технические работы: заходить могут только OP.
- **Анти-чит**: подозрения на читы приходят персоналу с правом `herplun.anti-cheat`.
- **`/gm` и `/gamemode`** — смена режима игры, как в Essentials.
- Улучшения качества (см. ниже).

---

## Как обновиться с 1.1 / 1.0

Переустанавливать с нуля не нужно:

1. Остановите сервер.
2. Замените `HerPlun.jar` в папке `plugins` на новый.
3. Запустите сервер.

Баны, муты и настройки сохраняются. Новые пункты настроек подхватываются сами
(значения по умолчанию). Чтобы увидеть их в вашем `config.yml`, удалите старый файл
(сначала сохраните копию) и он создастся заново.

## Команды

| Команда | Что делает | Право |
|---|---|---|
| `/ban <игрок> [причина]` | Бан навсегда | `herplun.ban` |
| `/unban <игрок>` | Разбан | `herplun.unban` |
| `/timeban <игрок> <время> [причина]` | Временный бан | `herplun.timeban` |
| `/mute <игрок> [время]` | Мут (без времени — навсегда) | `herplun.mute` |
| `/unmute <игрок>` | Снять мут | `herplun.unmute` |
| `/help` | Список команд (только доступные вам) | `herplun.help` |
| `/report <игрок> <причина>` | Подать жалобу | `herplun.report` |
| `/report cancel <номер>` | Отменить свою жалобу | `herplun.report` |
| `/report open` | Открыть меню жалоб | `herplun.open` |
| `/voice` | Ссылка на голосовой чат | `herplun.voice` |
| `/check on <игрок> <время>` | Вызвать на проверку читов | `herplun.check.on` |
| `/check off [игрок]` | Завершить проверку | `herplun.check.off` |
| `/check tp` | Телепорт к проверяемому | `herplun.check.tp` |
| `/check time <время>` | Продлить проверку | `herplun.check.time` |
| `/gm <режим> [игрок]` | Сменить режим игры | `herplun.gm` |
| `/gamemode <режим> [игрок]` | Сменить режим игры | `herplun.gamemode` |
| `/herplun privilege set <игрок> <привилегия>` | Выдать навсегда | `herplun.privilege` |
| `/herplun privilege addtemp <игрок> <привилегия> <время>` | Выдать на время | `herplun.privilege` |
| `/herplun privilege remove <игрок> <привилегия>` | Снять | `herplun.privilege` |
| `/herplun technical on/off` | Технические работы | `herplun.technical` |
| `/herplun reload` | Перезагрузить настройки | OP или `herplun.technical` |

**Время:** `s` секунды, `m` минуты, `h` часы, `d` дни, `w` недели (`30m`, `12h`, `1d2h30m`).
**Режимы `/gm`:** `0/s` выживание, `1/c` творческий, `2/a` приключение, `3/sp` наблюдатель.

Если права нет, игрок увидит: `"HerPlun" У вас нет прав что прописать команду!`

## Права

```
herplun.ban          herplun.unban        herplun.timeban
herplun.mute         herplun.unmute       herplun.help
herplun.report       herplun.open         herplun.voice
herplun.privilege    herplun.technical    herplun.gm
herplun.gamemode     herplun.anti-cheat
herplun.check.on     herplun.check.off    herplun.check.tp
herplun.check.time
```

По умолчанию `herplun.help`, `herplun.report`, `herplun.open`, `herplun.voice`
доступны всем, остальные — только OP.

---

## Меню жалоб (`/report open`)

- **Обычный игрок** видит только свои жалобы. **ЛКМ** по жалобе — отменить её.
- **Модератор** (право `herplun.check.on`) видит все жалобы. **ПКМ** — закрыть
  жалобу как рассмотренную (автор получит уведомление).
- Стрелки внизу — смена страницы.
- Ограничения (в `config.yml`): пауза между жалобами и максимум открытых жалоб.

Новые жалобы приходят модераторам в чат.

---

## Технические работы

`/herplun technical on` — все игроки, кроме OP, выкидываются с сервера и не
могут зайти. `/herplun technical off` — вход снова открыт. Состояние
сохраняется после перезапуска сервера.

---

## Анти-чит

Видят сообщения игроки с правом `herplun.anti-cheat`. Плагин **только
предупреждает** и никого не наказывает автоматически.

Проверки:
- **Fly** — зависание или подъём в воздухе без опоры.
- **Speed** — слишком высокая средняя скорость.
- **Reach** — удар по игроку с слишком большого расстояния.
- **KillAura** — удар по игроку, на которого атакующий не смотрит.

> ⚠️ Это простой анти-чит. Возможны **ложные срабатывания** (лаги, плагины
> на полёт и телепорты, моды). Перед наказанием проверяйте игрока через
> `/check on`. Пороги настраиваются в разделе `anticheat` в `config.yml`.
> Полноценный анти-чит (Grim, Vulcan и т.п.) он не заменяет.

## Файлы данных (`plugins/HerPlun/`)

| Файл | Что хранит |
|---|---|
| `config.yml` | Настройки |
| `bans.yml` | Баны, выданные через HerPlun (причина, кто, когда, до когда) |
| `mutes.yml` | Муты |
| `reports.yml` | Жалобы |
| `state.yml` | Состояние (технические работы) |

Файлы лучше не править вручную при работающем сервере.

---

## Настройка (`config.yml`)

Можно изменить префикс, сообщения, ссылку для `/voice`, список команд,
запрещённых замученным, лимиты жалоб и пороги анти-чита.

> ⚠️ **Внимание!** Ошибка в `config.yml` (лишний пробел, неверный отступ,
> пропущенная кавычка) может сломать плагин, а в худшем случае привести к
> **краху сервера**. Перед правкой сделайте копию. Меняйте только текст и числа.
> Если что-то сломалось — удалите `config.yml`, он создастся заново.

## Привилегии

Команда `/herplun privilege` управляет **группами LuckPerms**, нужен плагин
LuckPerms. Группу создайте заранее: `/lp creategroup vip`.

---

## Что улучшено в 1.2

- Код разделён на несколько классов (раньше всё было в одном файле).
- Данные хранятся в отдельных файлах и не теряются при перезапуске.
- Уведомления персоналу теперь доходят всем, у кого есть право в LuckPerms
  (раньше они могли не доходить игрокам, которым право выдано не через OP).
- Ошибка в одной команде больше не ломает остальные: она пишется в консоль.
- Защита от спама жалобами, проверка существования игрока.
- `/help` показывает только те команды, которые доступны игроку.
- Добавлена команда `/herplun reload`.

---

## Возможные конфликты

Команды `/ban`, `/unban`, `/mute`, `/help`, `/gamemode` есть в других плагинах
и в самой игре. Если срабатывает не та команда, пишите `/herplun:ban`,
`/herplun:gamemode` и так далее.

## Сборка .jar через GitHub

1. Загрузите все файлы проекта в репозиторий GitHub.
2. Вкладка **Actions** → **Build HerPlun** → последний запуск.
3. Внизу в **Artifacts** скачайте `HerPlun`. Внутри лежит `HerPlun.jar`.
